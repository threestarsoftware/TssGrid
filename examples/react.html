TssGrid × React @threestarsoftware/tssgrid/react

薄い公式アダプタ。グリッドはアンコントロールド（マウントで生成・アンマウントで destroy()）、cell は React で描かない（高速）。値は ref 経由の命令API（grid 本体）＋ onAfterChange。
このページは CDN の React（UMD）＋アダプタを <script> で読むノービルドデモ。実アプリでは import { TssGridReact } from '@threestarsoftware/tssgrid/react'。

差し込み（抜粋）

import { useRef } from 'react';
import { TssGridReact } from '@threestarsoftware/tssgrid/react';
import '@threestarsoftware/tssgrid/tssgrid.css';

const ref = useRef(null);
<TssGridReact columns={cols} data={rows}
  onAfterChange={(ch, src) => console.log('changed', ch, src)} ref={ref} />
// 命令API: ref.current.sortBy('age','desc') / ref.current.getRows()
