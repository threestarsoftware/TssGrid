TssGrid 例: 表示専用と選択の制御 cursor readOnly onBeforeSelectionChange toEdit

「見せるだけの表」「一部だけ編集させない」「選べるセルを絞る」「ボタンから入力を始める」をまとめました。

① 見せるだけの表（選択枠を出さない）

readOnly: true で編集できなくなり、cursor: false で青い選択枠も出なくなります（集計表・一覧の表示用）。
それでも ドラッグして Ctrl+C でコピーはできます（内部では選択を持っている）。
読み取り専用のセルはふだん灰色ですが、この2つを両方付けた「見せるだけの表」は普通の色で表示します（列やセル単位のロックは従来どおり灰色）。

② 一部だけ編集させない

表全体は setReadOnly(true/false) で切り替え。列は columns[c].readOnly、関数にすると行ごとに判定できます（ここでは「状態が済」の行の金額はロック）。
選んだセルだけロックするなら setCellReadOnly(true)。ロックされたセルで打つ・F2・ダブルクリック・Delete・貼り付けなど変えようとすると、onReadOnly で知らせを受け取れます（ここでは赤字で表示。クリックで選ぶだけなら出ません）。

③ 選べるセルを絞る

onBeforeSelectionChange で false を返すと、その選択は起きません（クリック・矢印キー・ドラッグすべて）。
ここでは「合計」の行には入れない・選べるのは1セルだけ（範囲選択しない）にしています。範囲選択だけ止めたい・特定の列だけ止めたい、なども同じ書き方です。

④ ボタンから入力を始める

setActive(行, 列) でカーソルを動かし、toEdit() でそのセルを入力状態にします（列は data キーでも可）。「行を足してすぐ入力」「エラーのセルへ飛んで直してもらう」などに。
