TssGrid 例: 行の追加・削除と制限 insertRow deleteRows maxRows minRows allowInsertRows minSpareRows

行の追加・削除は、右クリックメニュー（行を上/下に挿入・行を削除）でも、ボタンから API でもできます。どちらも Ctrl+Z で元に戻せます。
行の削除アイコン（🗑）を各行に出す方法は 行削除アイコン の例を参照。

① ボタンで追加・削除する

insertRow(行, 'above'|'below') で1行、insertRows(行, 件数) でまとめて追加。deleteRows(先頭行, 最終行) で範囲を削除、行番号を Ctrl で飛び飛びに選んだ時は deleteRowsSet([行…])。
削除の前に確かめたい時は onBeforeStructureChange で false を返すと中止できます。

② 行数の上限・下限

maxRows: 5 で5行より増えない（右クリックの挿入・貼り付けで増える分・API もここで止まる）。minRows: 2 で2行より減らない（右クリックの削除も効かない）。
今の行数から「あと何行足せるか」を出してボタンを止めることもできます。

③ 利用者には追加・削除させない

allowInsertRows: false／allowDeleteRows: false で、右クリックメニューから行の挿入・削除が消え、insertRow／deleteRows も何もしません（決まった行数の表＝月の勤怠・固定の明細など）。列も同じく allowInsertCols／allowDeleteCols。
プログラムから行を足したい時は appendRows や setData を使います（こちらは止まりません）。

④ 末尾にいつも入力用の空行を置く

minSpareRows: 1 で、最後の行に何か入力すると、その下に空行が自動で1行増えます。「行を追加」ボタンなしで、下へ下へと入力していけます。
