TssGrid 例: ページネーション サーバ側ページング

ページネーションはサーバの API 形（offset/limit・total 件数の有無）に依存するので、TssGrid 本体は「渡された1ページ分を描く」だけに徹します。ロジックはアプリ側：ページ変更 → fetch（offset/limit）→ grid.setData(pageRows)、ページ番号ボタンや「N件中 M〜」はグリッドの外に置きます。
ここではモックのサーバ（全237件・遅延つき）を fetchPage(offset, limit) で叩き、{ rows, total } を受けて描画しています。total が返るので「全何件・何ページ」まで出せます（cursor だけで total 不明なら「もっと読む」＝appendRows の無限スクロール型にします）。
