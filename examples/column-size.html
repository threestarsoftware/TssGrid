TssGrid 例: 列幅と表のサイズ autoColumnSize stretchH height rowHeights headerWrap

列幅・表の幅と高さ・行の高さ・見出しの折り返しを、やりたいこと別にまとめました。
どの表も列の境目をドラッグで幅変更、境目をダブルクリックでその列を内容に合わせることができます（PC）。

① 列幅を内容に合わせる

autoColumnSize:true で、表を作った時に全列を中身（見出し含む）の幅にそろえます。数値を渡すと上限(px)になります（例 autoColumnSize: 240＝長い備考で列が伸びすぎない）。
データを入れ替えた後などは autoSizeAllColumns()（全列）／autoSizeColumn(c)（1列）を呼びます。

② 余白を埋める／横スクロールさせる

枠の幅は width（px か '100%' などの CSS 値）。列の合計が枠より狭いと右に余白が出ます。stretchH で埋め方を選べます。
'none'＝そのまま／'last'＝余りを最後の列へ／'all'＝全列で分け合う。枠を狭めて列の合計が枠より広くなると横スクロール（frozenCols で左の列を固定したまま）になります。
ウィンドウ幅を変えると追従します（隠し列は配分の対象外）。

③ 表の高さ（行数に合わせる／上限で止めてスクロール）

height を指定しない＝行数ぶん伸びる（ページごとスクロール）。height: 200 を指定するとその高さが上限になり、行が少ないうちは縮んだまま、超えたら表の中でスクロールします（見出しは上に固定）。
height 指定なし（行数ぶん伸びる）
height: 200（上限・超えたら中でスクロール）

④ 行の高さ

全体の既定は defaultRowHeight、行ごとの初期値は rowHeights（配列か { 行番号: px }）、あとから変えるのは setRowHeight(r, px)。
行番号の下端をドラッグで手で変えられます（resizeRows:false で禁止）。中身に合わせて高さを伸ばしたい時は列に wordWrap:true（折り返し）を付けます。

⑤ 長い見出しを折り返す

headerWrap:true で、見出しが列幅に収まらない時に折り返してヘッダ行を伸ばします（既定は1行で切る）。表の中をスクロールしても伸びた見出しは上に固定されたままです（行固定 frozenRows と併用しても、固定行は伸びた見出しの下にそろいます）。見出しは既定で中央寄せです。
