TssGrid 例: 行ごとのファイル添付 ボタン＋ドラッグ&ドロップ

各行の「添付ファイル」セルに、クリックで選択（＋追加）とファイルをドロップの両方で添付できます。どちらも同じ uploadForRow(r, file) に集約。
コツ：filePath 列の format は“そのセルの値”を第1引数で受け取るので、値があればファイル名＋差替/削除、無ければ「＋追加」ボタンを描くだけ。アップロード後は grid.setValue(r, 列, パス, true) でセルを更新（format が再実行）。
ドロップは ドロップ先セルの行を closest('tr[data-r]') で特定して、その行に添付します。dragover で preventDefault() しないと drop が来ない点に注意。
※このデモはサーバへ送らずファイル名だけ入れています（実アプリは POST → 返ってきたパスを setValue）。
