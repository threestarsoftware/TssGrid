TssGrid × Vue 3 @threestarsoftware/tssgrid/vue

薄い公式アダプタ。グリッドはアンコントロールド（マウントで生成・アンマウントで destroy()）。値は expose した grid 本体（命令API）＋ onAfterChange。
このページは CDN の Vue（グローバルビルド）＋アダプタを <script> で読むノービルドデモ。実アプリでは import { TssGridVue } from '@threestarsoftware/tssgrid/vue'。

差し込み（抜粋）

import { TssGridVue } from '@threestarsoftware/tssgrid/vue';
import '@threestarsoftware/tssgrid/tssgrid.css';

<TssGridVue :columns="cols" :data="rows"
  :options="{ onAfterChange: (ch, src) => log(ch) }" ref="g" />
// 命令API: this.$refs.g.grid().sortBy('age','desc')
