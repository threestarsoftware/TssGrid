TssGrid 例: セル内ボタン（行の状態で切替） html:true ＋ format ＋ click委譲

「操作」列のボタンを行の状態で出し分ける実務パターン。状態は列（状態）に持たせ、format の第3引数 row（その行の値配列）から読んで分岐します。
状態→ボタン：未申請＝申請/コピー／申請中＝編集/削除／編集中＝保存/取消。
⚠️ format の引数は (value, { r, c }, row)。row はその行の値配列（grid.data[r]・列 index で読む）。初回描画は構築中に走るので format の中で grid 変数を参照しない（まだ未代入＝TDZ）＝状態は row から読むのが安全。状態を変えたら grid.redraw() で再実行してボタン更新。
