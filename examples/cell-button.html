TssGrid 例: セル内ボタン html:true ＋ クリック委譲

専用のボタン列 API はありません。columns[c].html:true ＋ format が返す HTML でセルにボタンを描き、grid.table に click 委譲して data-act で拾う、が定石です。
ボタン列は readOnly:true にして編集モードに入らないように。行番号は closest('tr[data-r]') から取れます。
⚠️ html:true はエスケープを外すので、ボタンのラベルにユーザー入力を入れる時は自分でエスケープしてください（XSS 責任は HTML 提供側）。
